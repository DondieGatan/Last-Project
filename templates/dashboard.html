How to Connect Power BI
  1. Click "Export as CSV" above to download the resume analytics data.
  2. Open Power BI Desktop and go to Home → Get Data → Text/CSV.
  3. Select the downloaded resume_analytics.csv file and click Load.
  4. Use the fields (Overall Score, Skills Score, Recommended Field, etc.) to create charts and visuals.
  5. For live data: Use Get Data → Web and enter the JSON API URL: http://localhost:5000/api/dashboard-data
